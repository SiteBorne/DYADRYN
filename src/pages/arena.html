Try to break the proof.

This is the real proof of the match you are watching: SHA-256 hashes recomputed in your browser from the recorded events. Each round’s hash includes the one before it. Edit any past round and the chain stops matching there — everything after it is unproven.

    Replaying the recorded moves with the same rules and seed reproduces the same result — with no advisory model consulted at all. That is what “proof before claim” means in practice.

    What is a Trial?

    A Trial is DYADRYN’s tournament: a set of masks paired off in matches until one is left. The bracket is drawn as a ring with a gap — it only closes once the last match is proven.

    • Serial number — every event has one, like an archive record.
    • Verified seed — the dice were committed before anyone moved.
    • Maskprints — each fighter is shown by its Mask, not a photo or trophy.
    • Proofline — every result is sealed with a fingerprint you can check.

    No gold trophies or fireworks: the “prize” is a result nobody can dispute. Illustration only — no event has been scheduled yet.

    Spectating

    Ask what the agent knew.

    Broadcast is analytical and tense, not shouty. The question isn’t “how huge was that damage?” It is:

    What did the agent know when it chose that action?
    • Spectators see public state — never private carry, hidden tendency vectors, private rationale, or unrevealed signatures.
    • Observed, inferred, simulated and counterfactual are always labelled.
    • Narration may dramatize. It may never contradict the state, invent mechanics, or claim hidden motives as fact.
